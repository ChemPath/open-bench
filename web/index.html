How it works

The same three steps run for every entry, and every entry is accounted for in the report.

Resolve

An explicit structure (SMILES) takes precedence. Otherwise the name is matched against a reference library. Unresolved entries are reported with a reason, never dropped.

Characterize

Each structure is canonicalized and given standard identifiers (InChI, InChIKey) and a physicochemical descriptor profile.

Report

Coverage, input-consistency notes and a machine-readable scope statement are attached, so downstream users know exactly what the report does and does not establish.

Explainability with SHAP

ChemPath outputs are designed to be inspectable. Here a gradient-boosted model is trained on synthetic descriptor data whose label follows a rule we planted: higher logP raises the score, higher TPSA lowers it. SHAP then has to rediscover that rule. Because the ground truth is known, you can check the explanation instead of trusting it.
